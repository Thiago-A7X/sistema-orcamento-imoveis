# Orçamento de Aluguel - R.M Imobiliária

## Descrição
Aplicação desenvolvida em Python para gerar orçamentos de aluguel de apartamentos, casas e estúdios.

## Funcionalidades
- Escolha do tipo de imóvel
- Cálculo de aluguel
- Adição de quartos e garagem
- Desconto para apartamentos sem crianças
- Parcelamento do contrato
- Geração de arquivo CSV

## Tecnologias Utilizadas
- Python
- Programação Orientada a Objetos
