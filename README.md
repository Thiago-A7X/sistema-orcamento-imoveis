# Sistema de Orçamento de Imóveis

## Descrição
Projeto desenvolvido em Python para geração de orçamentos de aluguel de apartamentos, casas e estúdios.

## Funcionalidades
- Escolha do tipo de imóvel
- Cálculo do aluguel
- Adição de quartos
- Adição de garagem
- Desconto para apartamentos sem crianças
- Parcelamento do contrato
- Geração de arquivo CSV

## Tecnologias Utilizadas
- Python
- Programação Orientada a Objetos (POO)
